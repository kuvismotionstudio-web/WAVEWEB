# 🌊 WAVEWEB

Modern Chromium-based browser built with Electron, featuring an AI sidebar powered by OpenAI.

## Features

- **Custom UI** – sleek dark theme with gradient accents
- **Tabbed browsing** – multiple tabs with favicons
- **AI Sidebar** – Wave AI assistant (OpenAI GPT-4o-mini)
  - Summarize pages
  - Translate content
  - Answer questions in context
- **Ad Blocker** – built-in tracker/ad blocking
- **Keyboard Shortcuts**:
  - `Ctrl+T` – New tab
  - `Ctrl+W` – Close tab
  - `Ctrl+R` – Reload
  - `Ctrl+L` – Focus URL bar
  - `Ctrl+B` – Toggle AI sidebar

## Setup

```bash
npm install
npm start
```

## AI Setup

1. Click the AI button in the toolbar (or press `Ctrl+B`)
2. Enter your OpenAI API key (`sk-...`)
3. Start chatting with Wave AI!

Get an API key at: https://platform.openai.com/api-keys
